# 中级密码学实验设计

## 目标与范围

Python 3.12 桌面应用，使用 Tkinter 和 TCP，在本机或局域网的两端双向传送文字、图片和视频文件。覆盖评分细则中的对称/非对称密码、Hash、密钥协商和可视化要求。

## 协议

- SM2 签名认证握手，SM2 公钥加密用于双方 32 字节随机挑战的往返验证；身份密钥以口令加密的自定义 JSON 容器保存（scrypt + AES-GCM），不把口令写盘。
- 每次连接生成 X25519 临时密钥和 32 字节随机数；双方 SM2 签名覆盖版本、角色、身份公钥、临时公钥和随机数。双方完整握手记录作为 HKDF-SM3 的上下文，派生两个方向的独立 SM4 和 HMAC-SM3 密钥。
- 首次使用在两个界面核对 SM3 身份指纹后手动确认；保存确认过的对端公钥指纹。身份变化拒绝连接，需用户删除对应信任记录后重新核验。
- SM2 适配层修复 gmssl 3.2.2 的安全边界：使用 secrets 随机源、保留以 0/4 开头的公钥坐标、验证曲线点与解密结果的 C3 摘要。曲线运算和 SM2 加解密仍调用库实现。
- SM4-CBC + PKCS7，逐记录随机 IV，Encrypt-then-MAC。HMAC 覆盖会话、方向对应密钥、序号、IV 和密文。先验 MAC 再解密。严格连续序号阻止重放和乱序。
- 长度前缀帧处理 TCP 拆包；最大帧、文字和文件大小限制。文件 64 KiB 分块传输，SM3 流式校验，临时文件仅在大小和摘要通过后原子改名，文件名本地净化且不覆盖已有文件。
- 本地实验按钮用独立临时通道演示篡改和重放拒绝，不破坏实际会话。

## 模块

- `securechat/crypto.py`：身份保存、SM2 签名、握手与加密记录。
- `securechat/protocol.py`：帧、连接、分块文件和生命周期。
- `securechat/gui.py`：主线程界面，网络工作线程通过队列通知界面。
- `main.py`：入口及双窗口演示。
- `tests/`：标准向量、安全负例、真实 TCP 双向文字和文件传输。

## 边界

这是教学应用，自定义协议未经过第三方审计；首次指纹必须通过可信渠道核对。SM2 身份签名与 X25519 密钥协商是混合方案，不称为全套国密协议。网络中断后保留已完成文件，清理未完成文件，重新连接重新协商密钥。文件传输限额默认 2 GiB，不提供实时音视频或断点续传。
